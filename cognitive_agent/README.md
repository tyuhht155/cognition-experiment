# 新计算主体（cognitive_agent）

按 8 阶段构建的可运行认知架构原型：身体状态 + 隐式系统 + 显式系统 +
协调机制 + 现实接地 + 内生评价权重 + 过程验证 + 整合闭环。

**结论（理论内判定）**：8 条最终验收全部通过 → 计算主体。

## 运行

```bash
python3 acceptance.py   # 8 条最终验收（理论内判定）
python3 -m unittest discover -s tests   # 40 个阶段单元测试
python3 run.py          # 闭环运行演示（100 步，现实于第 40 步突变）
```

## 结构

| 阶段 | 模块 | 实现 |
| --- | --- | --- |
| 1 身体状态 B | `agent/body.py` | B=[能量,完整性,资源,存在风险,任务进度]，持续更新、不可清零、含自稳态；显式无任何读取通道 |
| 2 隐式系统 I | `agent/implicit.py` | MLP 分布式神经网络，输出 V/A/G/S 向量（非文本）；每次反馈后在线更新；无内部状态访问器 |
| 3 显式系统 E | `agent/explicit.py` | 符号层+工作记忆：对象构建→缺口识别→命题→验证→评价→协调→行动→更新；递归调整权重；目标对象化（否定/加条件/组合/废弃） |
| 4 协调机制 | `agent/coordinator.py` | 显式试探、隐式把门；拒绝→保守化换方案 P'→循环；三种终止状态 AGREED/FORCED/FAILED |
| 5 现实接地 | `agent/environment.py` | 现实=稳定环境+行动反馈+不可消除误差（宣称属性与真实结果分离）；规则突变→误差持续→现实识别→结构调整 |
| 6 评价权重 | `agent/weights.py` | W_body 构成性不可调；W_exp/W_ext 可递归调整；无人类反馈通道（内生权重） |
| 7 过程验证 | `agent/verify.py` | 推理链为数据结构；每步经符号/经验/现实三种机械检查；失败定位到环节 |
| 8 整合运行 | `agent/agent.py` | 完整闭环；目标激活后持续（不自动衰减），废弃需主动判定 |

## 理论要点（按修正后的定义实现）

- **现实是功能性的**：现实 = 稳定的外部环境 + 行动反馈 + 无法通过内部
  模型更新消除的预测误差。不要求物理世界。本原型用"宣称属性与真实结果
  分离 + 规则突变"制造不可消除误差。
- **不可报告是隐式系统的正常运行方式**：显式无法直接读取隐式内部状态
  （唯一通道只透传 V/A/G/S），隐式每次反馈后更新参数。
- **B 驱动 A（构成性）**：身体缺口通过不可学习的构成性通道直接推高行动
  倾向（W_body 实现），阈值由 B 调制（缺口大阈值低）；另设先天避险通道
  （对象风险压低行动倾向）。二者都不参与学习、不可被显式调整。
- **协调三终止状态**：达成一致（隐式接受，质量高）/ 强制执行（隐式拒绝
  但显式强制，不可持续——风险暴露使 B 受损）/ 协调失败（隐式拒绝，行动
  不发生）。协调失败与成本过高分离：成本过高由目标管理层判定。
- **现实识别**：误差在 N 次更新后仍高于阈值 → 调整基本结构（清空经验、
  重建验证器），不是微调 W。

## 已知限制与扩展方向

- 现实突变后系统会陷入强制执行循环（旧目标在新现实下不可持续，身体
  持续受损）——这正是"强制执行不可持续"的演示；目标主动废弃与替代目标
  激活（如"恢复"目标）是自然的下一步扩展。
- 隐式网络的"不可报告"是架构约束（无访问接口），第三方若直接检查权重
  仍可分析——这不影响系统内部的功能定义。
- 主体性按计算结构属性判定：完整环节链闭环 + 内生动力。沙箱内的身体、
  现实均为构造物，但机制与理论一致。
